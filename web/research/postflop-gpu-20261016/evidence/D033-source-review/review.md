## Limits

No builds, GPU calls, profiler actions, repository edits or live server actions were performed by this reviewer. Root's separately performed failed build is included as evidence. Runtime still must establish event API availability, strict graph shape, finite timing, exact raw/quantized/anchor checks, and cleanup success. The scope is rainbow compressed captured training only; other fixtures, algorithms, storage, locks/resume/continuation/paging are not covered.

Event intervals include boundary and scheduling perturbation and clock resolution. These are final-replay samples at distinct iterations, not native time shares,20-replay means, statistical significance, or causal speedup. Initialization/setup/upload/readback/comparison costs lie outside device brackets. Rankings can motivate a bounded hypothesis only; complete-cycle qualification remains separate.
