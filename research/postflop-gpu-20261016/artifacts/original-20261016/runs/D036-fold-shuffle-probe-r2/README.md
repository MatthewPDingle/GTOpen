# D036 standalone fold-kernel probe

Prepared only, outside the checkout. No rustc, Cargo, CUDA invocation or kernel launch was performed during preparation. Root executes only after independent review and ownership of the serialized build/GPU slot. This is a numerical/compiler diagnostic with no solver timing or acceptance claim.

The baseline is the complete accepted E015 CUDA source, SHA256 `8fe86cb859124592f9df13821f4a300450045620e6947e99466e4228b78c20d0`. The candidate changes only the reduction inside `up_fold`: the current 128x1x1 shape keeps shared steps64/32 and their barriers, then all32 lanes of warp0 shuffle before guarded additions16/8/4/2/1. Lane0 publishes, followed by a block-wide barrier. Every other shape retains the original loop. No kernel arguments, card sums, float partial order, payout arithmetic, output addressing, other kernel, host constructor or graph lifecycle changes. The complete source pair compiles as separate modules in one context. Full compiled `up_fold` is the authoritative numerical comparison.

`raw-baseline.cu` and `raw-candidate.cu` are supplementary exposures of the exact source partial/reduction blocks, extracted mechanically rather than hand-transcribed. Their totals additionally compare to a CPU f32 same-tree oracle on the finite-output domain. They do not substitute for full-kernel comparisons.

## Fixed workload

`corpus.json` freezes every float as a u32 IEEE bit pattern, all hand/card/same-hand mappings, node order, reach/CFV slots and the xorshift seed before any execution. The16 opponent lengths are0,1,31,32,33,63,64,65,127,128,129,255,256,257,319,1326. The14 patterns are positive/negative/mixed zero, ones, sparse0..1 reaches, random finite exponents, rounding boundaries, subnormals, normal/subnormal boundaries, tiny/large mixtures, finite cancellation, negative finite values, lane-boundary values and finite-overflow values. Thirteen pattern domains must produce finite outputs; the overflow domain is separately reported but **every observed baseline/candidate bit still must match**, including resulting Inf/NaN bits. Any mismatch invalidates the probe. This is no universal NaN payload claim, and no NaN/Inf input values are supplied.

There are224 raw cases and17 full scenarios (the16 opponent lengths plus explicit own-hand count0). Full scenarios contain56 terminal nodes:14 patterns times4 owner/payout combinations. Both traversers run; payout values include positive wins, negative losses, +0 and -0. Opponent and own ranges are deterministic permutations of all1326 legal two-card hands. Each opponent card list preserves original opponent-hand order; `same_p` is derived from exact hand identity. Start is2, the launch has two excess blocks, list positions outside the active interval contain invalid node IDs, physical reach slots and output slots are nontrivial permutations with disjoint unused guard slots. Hand-loop tails and asymmetric257/319 hands are included. A separate zero-count call on the n0 scenario validates the uniform early return for each shape/player.

Every pair uses the same block shape, in order128,16,32,64,256. Fallback results are compared with their own baseline shape; no cross-shape reduction equality is assumed. The17 scenarios times2 players times5 shapes give170 full launch pairs, plus10 additional zero-count pairs on the n0 scenario. There are1120 raw case pairs (1040 also finite-domain CPU comparisons),180 full launch pairs and370 kernel launches total. Expected stage counts are one harness check, eight resource rows, five raw-total rows,180 full-kernel rows, one completion. The resource rows query block128 at dynamic shared sizes0,1028,1276,5304 bytes: actual opponent sizes257/319 and maximum1326, plus zero. They report registers/local/static shared and theoretical occupancy, never speed.

Both output images are retained in `raw-results.jsonl` before equivalence checks. Every unwritten output word is checked against its initial stale finite sentinel, including CFV gaps/tails, raw output guards, zero-count calls and zero-own-hand cases. Every device input buffer is read back and compared bitwise after **each** variant, including all metadata, so a baseline mutation cannot contaminate the candidate unnoticed. Required full outputs must include nonzero values; all-zero equivalence cannot close the diagnostic. Nonfinite output counts, bits and their domain are explicit. The host expected-bit and guard-verifier injection self-checks intentionally reject fabricated mismatches; they are not counted as CUDA numerical cases.

CUDA12.4.1 [warp shuffle semantics](https://docs.nvidia.com/cuda/archive/12.4.1/cuda-c-programming-guide/index.html#warp-shuffle-functions) require named active lanes to execute the same collective. The shuffle transfers register values; the retained block barrier publishes the final shared result. This probe deliberately tests the compiled arithmetic because the accepted PTX previously reversed source operand roles in a shared add.
