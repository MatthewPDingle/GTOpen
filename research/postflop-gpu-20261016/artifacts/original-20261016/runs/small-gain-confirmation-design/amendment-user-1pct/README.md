# User-directed 1% amendment proposal

Use the explicit user cutoff: aggregate complete-cycle gain must be at least 1%. Keep the median paired gain merely positive, at least 13/16 positive pairs, and a positive median in every block and both execution-order strata. This avoids adding a second 1% gate the user did not request.

Replace the old 3% fixture allowance with no observed repeatable fixture slowdown: a positive fixture median slowdown plus at least 9/16 positive paired slowdowns rejects. All exactness, source/custody and later broader controls remain mandatory; material memory or compatibility costs are unacceptable. This screen cannot establish absence of tradeoffs outside the tested scope.

Report all observed sizes and variability. Tiny systematic bias and serial dependence remain possible, so no calibrated confidence or significance claim follows. A true 1% effect may estimate below 1% and fail; this cutoff now reflects the user's choice. No old samples, cherry-picking, replacement runs or extensions.

Keep this design pending E037's outcome and the root baseline decision. E037's initial qualifying screen is not adoption. If eventually adopted, recheck whether E036 is subsumed and all other changes remain meaningful; do not undo E037. No source/build or execution schedule is frozen here. A single constrained random BC/CB schedule remains the recommended later ordering choice, with all balanced pairs explicit before runtime.

The v1 and no-magnitude proposal remain byte-exact. The final prospective protocol must explicitly supersede their conflicting thresholds; downstream scripts must not accidentally consume old fields.
