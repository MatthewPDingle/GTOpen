# Large conditional refinement and GPU variance reduction

Goal: scale branch refinement to large games, then test variance reduction on
the GPU. Large-game conditional accuracy must be qualified before deployment.
Do not declare completion from a small-fixture success or a synthetic estimator
alone. Preserve the live app on 56708 and push research evidence to GitHub.

First registered stage: admit parent games up to two million nodes while
retaining the 10,000-node-per-selected-subtree and 1,000-local-iteration bounds.
Inventory the six existing audit paths on `eight-native-a` and
`followup-eight-gamma15-s64-42` before running refinement. Use all canonical
1,024 particles in local learning and the final global GPU evaluation. Verify
every unrelated/fixed arena exactly, native roundtrip, unchanged global iteration,
and all six local gates afterward. These remain offline artifacts: local ages
are not compatible with ordinary global resume.

Once inventory confirms the bounds, run each original snapshot with 1,000
iterations per selected root, upstream to downstream, with a 3,600-second cap
per snapshot. Record all time, full global gap, conditional errors, hashes and
failures. Passing these six paths is necessary but not sufficient for broad
large-game qualification; expand coverage before deployment.

Subsequent work must test an actual GPU variance-reduction implementation with
reference refresh, memory and timing costs. Do not substitute a CPU/synthetic
screen for that requirement. Register its numerical/equivalence and convergence
tests before observing their outcomes.

All hardware work is serial. A read-only live guard stops only owned research
if the user starts a solve/report. Do not restart the live server or load an
experimental save there.

GPU CV numerical screen, registered before execution: a four-seat, five-BB,
raw-realization limping fixture runs three DCFR iterations. At 1,024 particles,
the correction must cancel exactly (all arenas and full-check gaps identical).
At 64 particles with a fresh reference every iteration, normalized arena error
abs(candidate-reference)/(1+abs(reference)) and absolute gap error must each
stay at or below 0.0002. Reject nonfinite values. Test zero memory allowance
rejection before allocating a valid reference. These numerical tests alone do
not qualify convergence, large-memory behavior, or production deployment.

GPU convergence screen: use the unchanged pass-05 six-solver fixture, gamma15,
64 particles, seeds 42 and 314159, check every 25 iterations, maximum 1,000
iterations and 600 seconds per run. Compare CV disabled with refresh intervals
32 and 64. Stop after two full-model gaps at or below 0.005 bb. Include actual
GPU reference refresh costs, eager launch costs, extra memory, initialization,
and serialization. Keep failures/timeouts. Do not select on iteration counts
alone; compare elapsed time and conditional accuracy before recommending.

Large CV probe: unchanged eight-player pass-03 user-session fixture, one
gamma15/64 iteration, refresh 32, full check, 180-second cap, 4-GiB extra CV
storage allowance. Record an allocation rejection as a scaling failure, not
as a convergence result. Do not increase the memory allowance after seeing
the outcome without a separately documented storage-design change.

Expanded large conditional qualification: 27 explicit paths, selected before
their quality evaluation. Cover both offered non-jam opening sizes at BTN,
SB and BB, with zero/one/two callers, plus responses to BTN's first re-raise;
also cover one/two/three early limpers at BTN, SB and BB. See broad-paths.json
generated by run_broad.py. Audit both previously refined large snapshots. All
errors, unreachable paths and failures remain in the report; none count as
passing. Same 0.10 probability / 0.10 bb loss / 0.0025 hand-mass gate.

If 1,000 iterations fails, permit a separately timed fresh 4,000-iteration
refinement at failed roots, preserving the 10,000-node subtree limit. Re-audit
all 27 paths afterward, because changing an upstream subtree can invalidate
earlier downstream checks. This is additional work, not a rewritten initial
result. Source iteration cap raised to 4,000 only in the offline research API.

Adaptive expanded experiment: walk the registered 27 paths upstream to
downstream. Skip paths that already pass. At failed roots, try 1,000 fresh
