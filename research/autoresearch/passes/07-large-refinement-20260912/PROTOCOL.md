# Large conditional refinement and GPU variance reduction

Goal: scale branch refinement to large games, then test variance reduction on
the GPU. Large-game conditional accuracy must be qualified before deployment.
Do not declare completion from a small-fixture success or a synthetic estimator
alone. Preserve the live app on 56708 and push research evidence to GitHub.

First registered stage: admit parent games up to two million nodes while
retaining the 10,000-node-per-selected-subtree and 1,000-local-iteration bounds.
Inventory the six existing audit paths on `eight-native-a` and
`followup-eight-gamma15-s64-42` before running refinement. Use all canonical
1,024 particles in local learning and the final global GPU evaluation. Verify
every unrelated/fixed arena exactly, native roundtrip, unchanged global iteration,
and all six local gates afterward. These remain offline artifacts: local ages
are not compatible with ordinary global resume.

Once inventory confirms the bounds, run each original snapshot with 1,000
iterations per selected root, upstream to downstream, with a 3,600-second cap
per snapshot. Record all time, full global gap, conditional errors, hashes and
failures. Passing these six paths is necessary but not sufficient for broad
large-game qualification; expand coverage before deployment.

Subsequent work must test an actual GPU variance-reduction implementation with
reference refresh, memory and timing costs. Do not substitute a CPU/synthetic
screen for that requirement. Register its numerical/equivalence and convergence
tests before observing their outcomes.

All hardware work is serial. A read-only live guard stops only owned research
if the user starts a solve/report. Do not restart the live server or load an
experimental save there.

GPU CV numerical screen, registered before execution: a four-seat, five-BB,
raw-realization limping fixture runs three DCFR iterations. At 1,024 particles,
the correction must cancel exactly (all arenas and full-check gaps identical).
At 64 particles with a fresh reference every iteration, normalized arena error
abs(candidate-reference)/(1+abs(reference)) and absolute gap error must each
stay at or below 0.0002. Reject nonfinite values. Test zero memory allowance
rejection before allocating a valid reference. These numerical tests alone do
not qualify convergence, large-memory behavior, or production deployment.

GPU convergence screen: use the unchanged pass-05 six-solver fixture, gamma15,
64 particles, seeds 42 and 314159, check every 25 iterations, maximum 1,000
iterations and 600 seconds per run. Compare CV disabled with refresh intervals
32 and 64. Stop after two full-model gaps at or below 0.005 bb. Include actual
GPU reference refresh costs, eager launch costs, extra memory, initialization,
and serialization. Keep failures/timeouts. Do not select on iteration counts
alone; compare elapsed time and conditional accuracy before recommending.

Large CV probe: unchanged eight-player pass-03 user-session fixture, one
gamma15/64 iteration, refresh 32, full check, 180-second cap, 4-GiB extra CV
storage allowance. Record an allocation rejection as a scaling failure, not
as a convergence result. Do not increase the memory allowance after seeing
the outcome without a separately documented storage-design change.

Expanded large conditional qualification: 27 explicit paths, selected before
their quality evaluation. Cover both offered non-jam opening sizes at BTN,
SB and BB, with zero/one/two callers, plus responses to BTN's first re-raise;
also cover one/two/three early limpers at BTN, SB and BB. See broad-paths.json
generated by run_broad.py. Audit both previously refined large snapshots. All
errors, unreachable paths and failures remain in the report; none count as
passing. Same 0.10 probability / 0.10 bb loss / 0.0025 hand-mass gate.

If 1,000 iterations fails, permit a separately timed fresh 4,000-iteration
refinement at failed roots, preserving the 10,000-node subtree limit. Re-audit
all 27 paths afterward, because changing an upstream subtree can invalidate
earlier downstream checks. This is additional work, not a rewritten initial
result. Source iteration cap raised to 4,000 only in the offline research API.

Adaptive expanded experiment: walk the registered 27 paths upstream to
downstream. Skip paths that already pass. At failed roots, try 1,000 fresh
iterations, then 4,000 fresh iterations only if the root still fails. Repeat
this ordered audit/refine pass at most twice, then independently audit all 27
and check the canonical global gap. This intentionally counts the discarded
1,000-iteration trial in total time. Cap each whole snapshot at 3,600 seconds.
Do not normalize away zero prefix reach; upstream refinement must make such a
path reachable or the run records failure. Preserve all original evidence.

Adaptive v1 was rejected before mutation: at least one of the multi-limper
subtrees exceeded the 10,000-node refinement cap (the read-only audit permits
50,000). For v2, first inventory the full 27-path set with an explicit
50,000-node cap per root, matching the existing audit bound. Retain the

Adaptive v2 was explicitly stopped after 116 seconds by terminating only the
verified owned research process. Its historical audit calls deemed nonzero
joint reach below 1e-12 unreachable even after successful local refinement.
No result was published or loaded. The original input remains immutable.

For v3, keep the historical audit API and add a conditioned audit: normalize
each positive seat range before evaluation, retain raw reach in metadata,
and divide by normalized counterfactual mass. This removes arbitrary tiny
joint-reach cutoffs without changing the 0.10/0.10/0.0025 action-quality gate.
Actual zero or nonfinite per-seat reach remains unevaluable. Check invariance
of per-hand action values within 0.0001 bb on ordinary and artificially tiny
positive prefixes, plus rejection of an actual zero prefix, before execution.

Compact GPU branch prototype (not the rejected CV estimator): extract at most
50,000 nodes and supply normalized per-seat incoming ranges. Use the same
full 1,024-particle DCFR calculation and fresh local age as the CPU reference.
Before timing, compare 50 CPU/GPU iterations on four-seat raw and calibrated
limped branches with nonuniform incoming ranges. The calibrated case includes

per-hand root action-value discrepancy <=0.005 bb, exact unrelated/fixed arena
preservation, unchanged global age, and no parent mutation on pre-cancellation.
Reserve extra root-buffer memory inside the requested GPU budget. Do not run
these tests concurrently with the frozen CPU qualification experiment.

After the compact CPU/GPU tests pass, run the same 27-path adaptive procedure
on the same initial large sampled and native snapshots using the compact GPU
engine, full 1,024 particles, 4,096-MB per-branch budget, and the same local
iteration choices. Preserve the 3,600-second process cap and all global/local
accuracy and arena invariants. Compare end-to-end time, including extraction,
GPU initialization, full checks, audits, save and reload. A faster result does
not pass if its final conditional audit or full global gap fails.

average strategy. Reset every learning-node regret block to that normalized
policy (scale 1), reset learning averages to zero, and set global iteration to
zero. Preserve frozen/forced arena blocks exactly. This avoids pretending mixed
local ages are valid global history. It is a new solve, not a normal resume.

Test seeding/constraint invariants before benchmarking. For both saved compact

as the global target; report total pipeline cost including preceding refinement.
A recovered global gap alone is insufficient. No CPU performance benchmarking
is part of this experiment, following the user's steering.

forced-node averages. The learning mask had stopped updates but not these

The strengthened test seeds positive/negative regrets and nonzero averages in
retained nodes. Run the same v1 numerical/performance protocol under new output
names after it passes. Keep failed v1 evidence; no v1 output was accepted.

# Joint upstream/downstream v1 (registered before execution)

Use both saved compact-v1 outputs. At most four cycles per input, each starting
with 25 full-1024-particle upstream GPU iterations on strict ancestors of the
minimal registered boundaries. Then visit all 27 paths in registered order;
skip passing paths, otherwise refine using fresh incoming ranges for 1,000
full-particle compact GPU iterations, escalating to 4,000 if still failing.
These are fresh local histories, not a resumed global solve.

After every complete cycle, use a fresh unrestricted full-1024 GPU evaluation
and an independent conditioned audit of all 27 paths. Stop early only when
global gap <=0.005 bb and all 27 pass the unchanged local gates. Save each cycle
with exact arena roundtrip checks and unchanged parent global age. Reuse the
tested per-operation fixed/retained arena checks. A true-zero unreachable
branch causing refinement refusal terminates the experiment; do not fabricate
an incoming range. Cap each input at 2,400 seconds, retain completed cycle
evidence if the cap is reached. Independently audit the final saved output.
No CPU performance work and no changes to port 56708.
