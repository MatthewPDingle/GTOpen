selection and port 56708 stay unchanged. Keep the retained cohort plan, alias
classifier, samples, scan and terminal arithmetic, learning graphs and criteria.

old CDF before allocating the compact table. Check final bytes plus 256 MiB
reserve against the supplied budget and check u32 element bounds. A failed
constructor drops the private engine; no damaged engine is returned. Inject real
CUDA allocation failure both before and after table replacement; verify pool
usage returns to its starting value and successful retry gives identical results.

all terminal values, required prefixes, zero-mass/recovery, 2-8 opponents,
partial batches 5 and 32, fixed seats/locks, exact full learning arenas, repeated
checks, graph/eager equivalence, stop flag and CPU synchronization. Add actual
save/reload continuation and interrupted-sweep replay before timing. Separately
validate small/large saved-state memory allocations against D19's byte plan.

require no spills, at most 64 registers, and only original 44-byte terminal
metadata shared memory. One guarded build/test at a time, 300-second build cap,
180-second fixture cap. Source immutable during a workload. Archive every trial.

Only after qualification run the first large control/candidate complete-work
pair. All six gap/EV checkpoints and complete arena fingerprint must match;

and default regressions. Retention still requires at least 3% median large gain
