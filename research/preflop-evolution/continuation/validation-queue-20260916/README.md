# Remaining frozen validation sequence

This controller waits for the actual N20 parent process (PID25056 at start),
verifying its command identity. A missing process alone does not prove success:
the N20 completion state, complete evaluation and independent reference audit
must also pass. It does not interrupt or restart that parent, its children or
the live app. A Windows file lock prevents duplicate validation queues.

After N20 exits, audit all 200 references and generate the descriptive hand
tables. Stop on any qualification failure. If qualified and at least 90 minutes
remain, run the already frozen N19 practical-stability diagnostic. N21's frozen
paired flop-menu study follows only if another 90 minutes remain. Generate the
checkpoint report. N19/N21 retain their original protocols and thresholds.
Failures preserve logs and require inspection, not an automatic retry.

All work respects the fixed 20:49:02 UTC deadline. This controller is a research
GPU owner between child stages too; do not launch concurrent research GPU jobs.
It never declares the user goal complete, commits partial artifacts, changes
the production model or deploys a build. The root task must audit outcomes,
archive/push finished evidence and make the final recommendation.
