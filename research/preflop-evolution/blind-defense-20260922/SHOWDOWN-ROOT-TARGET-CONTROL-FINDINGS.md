# Root-target correction control

The research adapter passes a 64-deal control from an already inspected training subbatch. It emits a distinct `showdown-controlled-bb-root-targets-v1` document; the existing learner does not accept this as its old target type, and no learner, checkpoint or production behavior was changed.

Call and raise coefficients are frozen as the equal-weight average of all four diagnostic banks and both parity fits. No winning bank was selected. The adapter authenticates query/policy bindings, context, physical deals, exact integer counts and root identity. It adjusts only call and raise, then recenters the four advantages under the played root probabilities. Fold and the exact initial-jam value are unchanged.

The control verifies zero-coefficient identity, unchanged source objects, unchanged fold/jam values, rejection of changed cards, and zero expected correction. Integrating the correction over loss/tie/win using each saved private pair's exact counts reproduces every original action target and advantage within 7.11e-15. This tests the correction's expectation, not the accuracy of the original continuation values.

Corrected quantities are learning estimators, not physical single-deal payouts; they must not be clipped to the original payout bounds. Such clipping could destroy the zero-mean property. Actual policy evaluation must continue to use unchanged game payoffs.

Remaining work is explicit training/checkpoint integration and a bounded fresh-seed generation to measure correctness, runtime and storage. Coefficients must be frozen before new target deals are drawn. Do not replay the old training seeds as a clean effectiveness test. A longer matched trial needs separate resource admission and unseen evaluation deals; this component control alone does not establish improved ranges.
