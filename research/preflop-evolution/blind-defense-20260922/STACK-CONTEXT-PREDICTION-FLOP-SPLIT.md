# Prediction diagnostic: public-flop separation implementation

The active matched learning comparison continues unchanged. This is one
qualified building block for the separately outstanding prediction diagnostic,
not an admitted experiment, target dataset, fitted model or accuracy finding.

`stack_context_flop_partition_v1.py` canonicalizes the initial public three-card
flop over all 24 suit permutations. An explicitly supplied namespace and bucket
configuration assign that group to fitting or testing. No experimental namespace,
bucket ratio, budgets or seeds have been chosen by this implementation. The
qualification configuration is synthetic and must not silently become the
scientific registration.

Every visible turn and river retains its initial flop's assignment. The module
accepts only the appropriate public street length and does not accept private
cards. It rejects using a hidden future board to assign a preflop row. A separate
predeclared preflop holdout unit remains required: independent target-noise draws
at a repeated preflop information set are not evidence of unseen-hand
generalization. Held-out stack contexts answer a different, useful question.

The exhaustive public catalogue contains 22,100 physical flops in 1,755 canonical
groups. Their suit-orbit multiplicities are 4, 12 or 24 physical flops; those
groups cannot be weighted uniformly to represent the full-deck distribution.
The catalogue records physical counts and each partition's conditional full-deck
denominator. Any future stratified sampling must preserve its declared population
and source weights, rather than treating canonical groups as equally frequent.

The CPU qualification passed in 1.532 seconds: it enumerated all physical flops,
independently closed all 1,755 suit orbits (42,120 suit transformations), tested
all six card orders for each canonical representative, checked 10,530 public
street descendants, verified physical population/weight denominators, and
rejected 17 corrupt/unsupported inputs. It drew no scientific hands, collected
no native labels, fitted no models and used no GPU. These are public geometry
and split tests, not poker accuracy tests.

Native target inspection confirms `hu_river_two_stage_stream_v1.rs` is explicitly
river-only: it requires the replayed state to be river and has no chance node in
the exported conditional future tree. `river_selected_native_values_v1.evaluate`
returns all legal action values, their teacher-weighted baseline and advantages
for a fixed river posterior sample. Earlier-street labels still need a qualified
common-teacher conditional future-card integration with exact all-in terms.
Existing sampled training-regret records cannot silently substitute for those
labels: they mix training generations and estimators, and target a different
quantity from a frozen complete-bank advantage.
