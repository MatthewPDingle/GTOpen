That plumbing alone does not prove that actual inference used the prospectively chosen complete A-baseline bank. The new fixed-teacher wrapper closes this binding gap without selecting a winner from the main comparison or changing it.

The actual loader requires the original same-study successful full-bank CUDA/reference gate and its authenticated selection/inputs. It recognizes only A-baseline's 362-input generations 0..63, with both actors' weights 1..64 and unplayed generation64 excluded. It loads/authenticates every played model and original local state using the qualified final-bank reader. The original prospective design identity is fixed. Context-specific averaging uses the existing PlayedBank and preserves its full own-action reach and local overrides. Native conditional plans must use the wrapper's exact immutable manifest with that actual teacher object.

Synthetic manifest controls establish selection, reference order, weights and pairing refusals only. They do not qualify actual 64-bank inference, CPU/GPU agreement on conditional hidden-hand queries, the resource envelope or model accuracy. The actual teacher is not yet loaded. No diagnostic data, label, fit, scientific experiment or production change is made here. Existing main training and handoff are unchanged.
