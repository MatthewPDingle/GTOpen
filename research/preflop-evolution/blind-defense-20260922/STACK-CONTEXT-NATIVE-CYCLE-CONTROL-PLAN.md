# Bounded full-context native training integration control

This is an implementation control, not a scientific learning comparison or a
trained model proposed for adoption. Freeze all inputs before its single attempt.
Retain failures and never rerun a started control under the same registration.

First compare cached CPU/CUDA raw scores, probabilities, positive support and
own-history reaches with the qualified reference on both 362/387 representations
and all seven retained query contexts. Use the existing nonuniform synthetic
routing fixtures only for this inference check, with their declared resources.
Require raw/probability/reach discrepancies no greater than 1e-10, equal positive
support and exact encoded features. Save arrays for subsequent readback.

Then use the new real stack resources and a fresh uniform 387-input full model
for one complete joint native cycle over 20/40/100/200/400bb. The 60/150bb contexts
remain inference-only. The geometry fixtures have broad UNSOLVED incoming ranges;
this does not select a scientific training population or a Wizard comparison.

Per fitting context use 169 class-stratified physical deals in 13-deal subbatches,
one independently planned complete five-card board, a 4,096-visit reservoir per
actor, all legal actions/streets and the unchanged posterior64 target estimator.
Freeze the same model while collecting all five contexts. Fit each shared actor
network for 16 ordered steps, chunk size512, learning rate.003 and fixed equal
context weights. The budget is sufficient to exercise the integration; it is
explicitly insufficient for a strategic convergence or accuracy claim.

Use two single-thread target workers and one single-thread full-board worker,
with CUDA current-policy scoring and shared fitting in the coordinator. Retain
raw native board and conditional-history/selected outputs, requests, policies,
target evidence, ordered visit counts and complete checkpoints. Verify all
native source identities and worker result bindings before reservoir insertion.

After collection, verify complete checkpoint restoration of sampler, action RNG,
reservoir arrays/RNG, local accumulators and played model identities. Exercise
publication interruptions using the retained real collected state and fitted
networks: the original state must remain unchanged and republishing the same
complete transaction must produce the same checkpoint. This checks publication
replay, not fresh native target recollection after a process crash.

On one retained 20bb board, change only BTN's river decisions to its first legal
action, independently re-integrate the tree and require an upstream BB root-value
change. This is a causal connectivity check, not evidence that the change helps.

Bound total work at40minutes, new retained logical data at4GB and coordinator CUDA
reservation at2GB. Admit only inside the existing800GB allocated research cap,
with40GB free disk and28GB free RAM; retain24GB running headroom. Share light
desktop activity, give production/heavy workloads priority, and keep56708 intact.
No scientific comparison, GitHub push, deployment or broad-goal completion.
